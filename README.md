## 📌 О проекте

Данный репозиторий содержит исследовательскую базу, аналитические материалы и программные модули, предназначенные для оценки возможности автоматизации требований национального стандарта **ГОСТ Р 56939-2024** «Защита информации. Разработка безопасного программного обеспечения. Общие требования».

* **Предмет исследования:** Разработка средства автоматизированной проверки процессов разработки безопасного программного обеспечения на соответствие требованиям ГОСТ Р 56939-2024 посредством сбора, анализа и оценки доказательств реализации установленных требований.

### Ключевые цели исследования:
* **Анализ требований ГОСТ:** Построчный разбор требований стандарта на предмет возможности их автоматизированной проверки.
* **Проектирование средства:** Разработка архитектуры модульного средства автоматизированной проверки с возможностью интеграции со специализированными инструментами и CI/CD-системами.
* **Оценка автоматизации:** Разработка критериев и методики оценки возможностей автоматизированной проверки требований и эффективности разработанного средства.

## 🗺️ Дорожная карта проекта

Разработка средства автоматизированной проверки разделена на три основных этапа.

### Основные этапы

- [x] **Этап 1. Анализ требований ГОСТ Р 56939-2024**
  - Проведён анализ процессов разработки безопасного ПО (пункты 5.1–5.25).
  - Определены требования к реализации процессов и соответствующие артефакты.
  - Оценены потенциал автоматизации и адаптивность проверок.
  - Подготовлены обоснования возможности автоматизированной проверки требований.

  Результат: [`docs/gost-56939-analysis.md`](docs/gost-56939-analysis.md).

- [x] **Этап 2. Отбор требований и проектирование автоматизированных проверок**
  - Выбраны требования ГОСТ для реализации в рамках ВКР.
  - Обоснован выбор с учётом актуальности, распространённости и реализуемости проверок.
  - Выполнен детальный разбор выбранных требований.
  - Спроектированы способы автоматизации, входные данные, выходные результаты и взаимодействие компонентов.

  Результат: [`docs/automation-design.md`](docs/automation-design.md).

- [ ] **Этап 3. Реализация и экспериментальная проверка**
  - Разработка программных модулей автоматизированной проверки.
  - Реализация ядра (оркестратора) для управления модулями и обработки результатов.
  - Разработка механизмов сбора метрик и формирования отчётов.
  - Интеграция с тестовым стендом и CI/CD-пайплайном.
  - Проведение экспериментов, анализ результатов и оценка эффективности разработанного средства.

  Результат: программный прототип средства автоматизированной проверки и результаты его экспериментальной оценки.

### Сопутствующие задачи

Выполняются параллельно с основными этапами по мере необходимости:

- Подготовка или получение доступа к тестовому стенду с CI/CD-пайплайном.
- Разработка механизма сбора и хранения метрик.
- Формирование и накопление отчётов о выполненных проверках.
- Версионирование программных модулей и сохранение стабильных версий.
- Подготовка методологии исследования, описания объекта и предмета исследования и итоговых материалов ВКР.
