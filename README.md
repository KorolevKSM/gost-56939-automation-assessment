## 📌 О проекте

Данный репозиторий содержит исследовательскую базу, аналитические материалы и программные модули, предназначенные для оценки возможности автоматизации требований национального стандарта **ГОСТ Р 56939-2024** «Защита информации. Разработка безопасного программного обеспечения. Общие требования».

### Ключевые цели исследования:
* **Анализ требований ГОСТа:** Построчный разбор подпунктов стандарта на предмет технической возможности внедрения автоматизированных инструментов (SAST, DAST, SCA, линтеры, оркестраторы).
* **Моделирование процессов:** Создание прототипа архитектуры управления ИБ-процессами в CI/CD (подход Security as a Code).
* **Метрики автоматизируемости:** Разработка формул и критериев оценки эффективности внедрения ИБ-инструментов.
